What is VirtualStage

VirtualStage is a 3D visualization tool for designing LED screen and projection surface layouts. Create, position, rotate, and scale multiple virtual screens in 3D space while receiving real-time video from applications like Resolume Arena via Syphon (macOS) or Spout (Windows).

Use it to preview stage setups before the build, design multi-screen layouts for live shows, test video content across configurations, or import layouts directly from Resolume Advanced Output.

Installation

macOS

  1. Download and unzip VirtualStage-macOS.zip
  2. Right-click the app and select Open (first time only)
  3. If macOS says the app is damaged, run in Terminal: 
    xattr -cr /path/to/VirtualStage.app

Windows

  1. Download and unzip VirtualStage-Windows.zip
  2. Run VirtualStage.exe

On first launch, sign in or register a new account. Your account enables cloud project saving and preference syncing.

Interface Overview

  • Menu Bar — File (new, open, save, cloud, autosave, quit), View (toggle property panels), Link (Resolume import), Help (manual, about)
  • Sidebar — SCREENS: lists all screens (click to select, [X] to delete). SERVERS: available video sources (click to assign to selected screen)
  • 3D Viewport — The main area where screens are displayed. Orbit, zoom, pan, select, and transform screens here
  • Properties Panel (right) — Appears when a screen is selected. Edit Position, Rotation, Size, Curvature, Input Mapping, and Ambient Light
  • Toolbar (bottom center) — Shows the active gizmo mode (Move, Rotate, Scale)
  • Status Bar — Current mode (DESIGNER / VIEW), project name, FPS, server count

Work Modes

Designer is the main editing mode with all UI visible. View is a clean preview that hides the UI, goes always-on-top, and lets you lock the camera with the padlock button.

Working with Screens

Creating & Deleting

Add a screen with the [A]dd button in the sidebar header. Delete selected screens with the [X] button or the Delete key. Duplicate via right-click > Duplicate.

Selecting

Click a screen in the viewport or sidebar to select it. Hold Cmd/Ctrl+Click to multi-select, Shift+Click in the sidebar for range selection, or use area selection mode to drag a rectangle.

Screen Types

  • Flat — Standard rectangular screen (default)
  • Curved — Cylindrical arc, activated by changing the Curvature parameter (-180° to +180°)
  • Polygon — Non-rectangular masked screen, created when importing polygons from Resolume

Transforming

Use the 3D Gizmo to move, rotate, or scale screens. Switch gizmo mode with W/E/R keys. When multiple screens are selected, transformations apply to all of them. You can also type exact values in the properties panel (right-click any slider).

Video Sources

VirtualStage receives real-time video via Syphon (macOS) or Spout (Windows) from apps like Resolume, MadMapper, TouchDesigner, OBS, etc.

Assigning

Select a screen, then either click a server in the SERVERS sidebar list, press a number key (1-9), or right-click the screen and pick a server.

Disconnecting

Select the screen and press D, or right-click > Disconnect.

Input Mapping Editor

Crops which portion of the video texture is displayed on a screen. Open it by selecting a screen and pressing M (or right-click > Map).

A yellow rectangle over the texture represents the crop area. Drag inside to move, drag corners or edges to resize. Toggle snap-to-grid for 5% alignment. Press R to reset to full frame. Close with M or Esc.

Importing from Resolume

Import layouts from Resolume Arena Advanced Output XML files. Press L to start (confirm with L again if screens already exist), then choose I for Input coordinates or O for Output coordinates.

VirtualStage auto-locates the most recent XML in the Resolume presets folder, or opens a file dialog. Each Slice becomes a flat screen and each Polygon becomes a polygon-masked screen, with crop regions calculated automatically.

Projects

Projects are saved as .json files containing all screen data, transforms, sources, crop settings, and camera state.

  • New — File > New Project
  • Save / Save As — Cmd/Ctrl+S or Cmd/Ctrl+Shift+S
  • Open — Cmd/Ctrl+O (restores everything and activates autosave)
  • Undo / Redo — Cmd/Ctrl+Z and Cmd/Ctrl+Shift+Z
  • Autosave — Toggle from File > Autosave (saves every 15s)
  • Cloud — File > Save to Cloud / Load from Cloud for cross-device access

Qué es VirtualStage

VirtualStage es una herramienta de visualización 3D para diseñar layouts de pantallas LED y superficies de proyección. Crea, posiciona, rota y escala múltiples pantallas virtuales en un espacio 3D mientras recibe video en tiempo real desde aplicaciones como Resolume Arena vía Syphon (macOS) o Spout (Windows).

Úsalo para previsualizar escenarios antes del montaje, diseñar layouts multi-pantalla para shows en vivo, probar contenido de video en diferentes configuraciones, o importar layouts directamente desde Resolume Advanced Output.

Instalación

macOS

  1. Descarga y descomprime VirtualStage-macOS.zip
  2. Haz clic derecho en la app y selecciona Abrir (solo la primera vez)
  3. Si macOS dice que la app está dañada, ejecuta en Terminal: 
    xattr -cr /ruta/a/VirtualStage.app

Windows

  1. Descarga y descomprime VirtualStage-Windows.zip
  2. Ejecuta VirtualStage.exe

Al abrir por primera vez, inicia sesión o registra una cuenta nueva. Tu cuenta permite guardar proyectos en la nube y sincronizar preferencias.

Modos de trabajo

Designer es el modo de edición principal con toda la UI visible. View es una vista limpia que oculta la UI, se pone siempre al frente, y permite bloquear la cámara con el botón de candado.

Trabajar con pantallas

Crear y eliminar

Agrega una pantalla con el botón [A]dd en el encabezado del sidebar. Elimina pantallas seleccionadas con el botón [X] o la tecla Delete. Duplica con clic derecho > Duplicate.

Seleccionar

Haz clic en una pantalla en el viewport o sidebar para seleccionarla. Mantén Cmd/Ctrl+Clic para multi-selección, Shift+Clic en el sidebar para selección por rango, o usa el modo de selección por área para arrastrar un rectángulo.

Tipos de pantalla

  • Flat — Pantalla rectangular estándar (por defecto)
  • Curved — Arco cilíndrico, se activa al cambiar el parámetro Curvature (-180° a +180°)
  • Polygon — Pantalla con máscara no rectangular, se crea al importar polígonos desde Resolume

Transformar

Usa el Gizmo 3D para mover, rotar o escalar pantallas. Cambia el modo con las teclas W/E/R. Con múltiples pantallas seleccionadas, las transformaciones se aplican a todas. También puedes escribir valores exactos en el panel de propiedades (clic derecho sobre cualquier slider).

Fuentes de video

VirtualStage recibe video en tiempo real vía Syphon (macOS) o Spout (Windows) desde apps como Resolume, MadMapper, TouchDesigner, OBS, etc.

Asignar

Selecciona una pantalla, luego haz clic en un servidor en la lista SERVERS del sidebar, presiona una tecla numérica (1-9), o haz clic derecho y elige un servidor.

Desconectar

Selecciona la pantalla y presiona D, o clic derecho > Disconnect.

Editor de Input Mapping

Recorta qué porción de la textura de video se muestra en una pantalla. Ábrelo seleccionando una pantalla y presionando M (o clic derecho > Map).

Un rectángulo amarillo sobre la textura representa el área de recorte. Arrastra dentro para mover, arrastra esquinas o bordes para redimensionar. Activa snap-to-grid para alineación al 5%. Presiona R para resetear al cuadro completo. Cierra con M o Esc.

Importar desde Resolume

Importa layouts desde archivos XML de Resolume Arena Advanced Output. Presiona L para iniciar (confirma con L si ya hay pantallas), luego elige I para coordenadas de Input u O para coordenadas de Output.

VirtualStage busca automáticamente el XML más reciente en la carpeta de presets de Resolume, o abre un diálogo de archivo. Cada Slice se convierte en una pantalla plana y cada Polygon en una pantalla con máscara poligonal, con regiones de crop calculadas automáticamente.

Proyectos

Los proyectos se guardan como archivos .json con todos los datos de pantallas, transformaciones, fuentes, crop y estado de cámara.

  • Nuevo — File > New Project
  • Guardar / Guardar como — Cmd/Ctrl+S o Cmd/Ctrl+Shift+S
  • Abrir — Cmd/Ctrl+O (restaura todo y activa autosave)
  • Deshacer / Rehacer — Cmd/Ctrl+Z y Cmd/Ctrl+Shift+Z
  • Autosave — Activa desde File > Autosave (guarda cada 15s)
  • Nube — File > Save to Cloud / Load from Cloud para acceso entre dispositivos
